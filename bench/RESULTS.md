## Findings

- **Top-1 accuracy does not separate the methods here.** Random ablation given the same number of model calls also reaches 100% top-1 (leave-one-out 93%), because planted triggers make culprits crisp. The differences are in what each method *claims*: false culprit rate 0% for AgentRelay vs 60% (leave-one-out) and 41% (random), and in cost.
- **Missed culprits are confidence, not ranking.** In 2 case(s), case_13 (p=0.50), case_21 (p=0.41), AgentRelay ranked the true culprit first but did not flag it: with a low failure rate, the 95% intervals of the baseline (20 trials) and the ablation (16 trials) overlapped, and explain only flags non-overlapping intervals. Re-running explain with doubled trials (40 / 32) flagged exactly the right unit in 2 of 2 (extra calls not counted above).
- **On small contexts leave-one-out can be cheaper.** For the 4 cases with 30 units or fewer, testing every unit costs about as much as AgentRelay's fixed overhead (baseline, confirmation, attribution), which is why the trials target only covers cases with more than 30 units.

## Notes and caveats

- **Synthetic and offline.** FakeLLM rules fire on exact trigger strings, so a culprit is either fully present or absent. Real models react to paraphrases and partial context, so these numbers are an upper bound on what to expect against a live model. The opt-in live bench (three examples against a real model) has not been run yet.
- **What counts.** Top-1: the rank-1 unit is a ground-truth culprit. Top-3: every culprit is in the top 3. False culprit rate: flagged units that are not ground truth, over all flagged units. Units are compared at the finest level (chunks, not whole tool results).
- **Cost** is model calls that missed the per-method trial cache (repeated questions are free, as they are for users). Simulated dollars use FakeLLM's $1/$5 per million tokens.
- **Leave-one-out** uses the same baseline (20 trials) and the same sequential test (3-8 trials) as AgentRelay's search, so the comparison isolates ddmin + targeted attribution against testing every unit. **Random ablation** gets exactly AgentRelay's call budget per case and ranks units by the difference in failure rate when kept versus dropped.
- Reproduce: `uv run python bench/generate.py && uv run python bench/run_bench.py`.
